## owner-animations

Tsukimichi already has a sound, allocation-free motion core: Motion.cs over MotionStore and MotionMath. It is driven by events only, pauses while scrolling, is cleared under Reduce motion, and has two tiers. Interaction motion follows Reduce motion alone. "Moon Road moments" need Flair Full (Theme.FlairMotion). The problem is coverage, not the engine. Hover easing exists only on chips, segmented controls, round icon buttons, Plan buttons and table rows. Tree rows, selections, action pills, tab and quest content swaps, filter result changes, banners, tooltips, popups and the overlay all change instantly. Several moments in the design docs were never built: the selection "settle" (MotionMath.SelectRate is defined but never used), the child fade on expand, asymmetric hover-out, the road glint and the station slide. One likely cause of "needs animations": Reduce motion defaults to Windows' "Show animations" switch. If that switch is off on the owner's PC, almost nothing in the plugin moves. Proposed spec: a token table of 120–350 ms entrances (exits 0.7× as long), opacity-only transitions for content that must not move (this pairs with item 3), and travel or waxing motion kept for the moon/bead ornaments. True fades come from FadeVertices on drawlists that stay within one window; the table's ScrollY child gets a veil drawn over it instead. Budget: under 0.05 ms per frame and zero allocations per frame.

## owner-static-layout

## plugin-icon-tech

The installer icon is a 512x512 PNG drawn in Pillow on 2026-09-27 (assets/icon.png, from assets/icons/render_icons.py and tsukimichi.svg). It hasn't changed since, and it is older than the Moon Road art the plugin now uses (crest, ornament atlas, category banners). Dalamud shows the icon at 64x64 × GlobalScale. It never makes mipmaps (MipLevels = 1, linear sampler), so a 512px source shrunk to 64 samples only 4 of every 64 texels. That is why the crescent edge looks jagged and the stars disappear in-game; a 128px source shrinks by an exact 2:1 and comes out clean. At 64px most of the art is lost: the stars are under 1.5px, the farthest stone is 0.75px, the 4% ground band is invisible and the 26% silver path barely shows on the navy. The green "installed" checkmark covers the bottom-right of the icon (about x≥42%, y≥54%), which is where the path and stones are. The flat #F2D27A crescent matches the "cheese" complaint, while the in-plugin crest and banners use a gradient moon and a moonlight road on water (the literal meaning of 月道). The installer accepts up to 5 images of at most 730x380, shows them as ~270x141 thumbnails and opens them full size on click.

## integrations

I checked every integration wrapper in Tsukimichi/Game against the companion plugins' current source on GitHub and against Dalamud's current plugin list (D17). No new companion plugin is needed. Wotsit, Quest Map, Chat 2, Allagan Tools and GatherBuddy are all maintained on API 15 (updated Aug–Sep 2026), so none should be dropped. The main integration problem is layout, and it is the owner's feedback #3: the detail pane draws 0–3 hand-off status lines under the action buttons, plus a 5-second hand-in note, and they push the content down whenever Questionable, AutoDuty, a walk or Artisan starts or stops. The fixed status bar at the bottom of the window already shows Questionable's status, so those lines can move there. Two things the current companions offer go unused. Questionable has `StartSingleQuest`, which does one quest and stops (Tsukimichi's Start button instead adds the quest to the priority list and starts automatic mode). Artisan has a stop gate, but the Craft button just goes disabled while Artisan works. Allagan Tools can create and show a craft list (`AddNewCraftList`/`EnableCraftList`). On the settings side (feedback #5), the Integrations section holds 11 blocks that mix companion plugins with the game's own windows, which is a large part of why it feels crammed. Tsukimichi's own IPC has 25 gates and no public consumer on GitHub, and outreach is not allowed, so it should stop growing.
