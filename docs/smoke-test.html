Before you start

  1. Build the plugin: dotnet build Tsukimichi.sln -c Debug in the repo folder.
  2. In game, type /xlsettings → Experimental → Dev Plugin Locations → add C:\Users\devon\Desktop\Tsukimichi (Main Repo)\Tsukimichi\bin\x64\Debug → Save and Close.
  3. Type /xlplugins → Dev Tools tab → enable Tsukimichi.
  4. Log in on your main character. For the Characters checks you will also need a second character on the account: log in on it once so a snapshot exists, then return to the main.
  5. Keep /xllog handy. Any red line mentioning Tsukimichi is worth pasting into a note.
